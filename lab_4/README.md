## Aim
To create and manage GitHub repositories, track issues, fork repositories, create pull requests, and perform code reviews.

## Learning Objectives
- Create and manage a GitHub repository.
- Create and track issues.
- Fork another repository and clone it locally.
- Create a feature branch and submit a pull request.
- Review proposed changes and merge an approved pull request.

## Software Requirements
- Git
- GitHub account
- GitHub CLI
- Web browser
- macOS Terminal

## Procedure
1. Create a GitHub repository.
2. Create an issue to track a task or enhancement.
3. Fork a classmate's repository.
4. Clone the fork and create a feature branch.
5. Modify a file, commit the changes, and push the branch.
6. Create a pull request.
7. Review the changes, provide feedback, and merge the pull request when approved.

## Result
The experiment demonstrates repository management, issue tracking, forking, pull requests, and code review using GitHub.
